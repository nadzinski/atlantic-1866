# Atlantic 1866

The Tyranny of Distance. Visualizing information and shipping in the Victorian Age. This map is built from shipping news printed in newspapers in the summer of 1866.

**Site:** https://atlantic-1866.com

Built from a private repository; this repo contains only the static site.
